# Suporte / Support

**Público:** quem usa o GUARACI · **Estado:** manual · **Atualizado em:** ver `docs/qualidade/estado_do_projeto.md`

O GUARACI é mantido por uma pessoa (ver [`GOVERNANCE.md`](GOVERNANCE.md)). O suporte é feito no tempo livre do mantenedor: **a meta é responder em até 7 dias úteis, sem garantia de prazo nem de solução.** Conversas públicas ajudam a próxima pessoa com a mesma dúvida, então prefira os canais públicos sempre que o assunto não for privado.

| Assunto | Canal |
|---|---|
| Dúvida de uso ("como faço…?", "como interpreto…?") | GitHub Discussions do repositório; antes, veja o [`MANUAL.md`](MANUAL.md) |
| Erro (bug) | GitHub Issues, com o formulário de erro |
| Sugestão de funcionalidade | GitHub Issues, com o formulário de sugestão |
| Vulnerabilidade de segurança | **Nunca em issue pública.** Use o canal privado do GitHub (aba *Security* → *Report a vulnerability*) e siga o [`SECURITY.md`](SECURITY.md) |
| Colaboração científica, licença, imprensa | GitHub Discussions do repositório (https://github.com/ErleySC/guaraci/discussions) |
| Como citar | [`CITATION.cff`](CITATION.cff) |

Ao relatar um erro, inclua a versão (`guaraci --version`), o sistema operacional, o comando ou a tela usada e a mensagem completa. Não anexe dado que você não pode tornar público.

---

*English:* GUARACI is maintained by one person in their spare time. The goal is a reply within 7 business days, with no guarantee. Usage questions go to GitHub Discussions, bugs and feature requests to GitHub Issues, security reports follow [`SECURITY.md`](SECURITY.md) (never a public issue), and anything else (collaboration, licensing, press) to GitHub Discussions. No e-mail address is published.
