# Governança / Governance

**Público:** quem usa ou quer contribuir · **Estado:** manual · **Atualizado em:** ver `docs/qualidade/estado_do_projeto.md`

## Quem mantém

O GUARACI é um projeto **individual**: foi idealizado, desenvolvido e é mantido por uma única pessoa, o autor indicado em [`CITATION.cff`](CITATION.cff). Não há equipe, empresa ou instituição por trás do software.

## Como as decisões são tomadas

- O mantenedor decide o que entra, o que sai e quando uma versão é publicada.
- Decisões que mudam resultado numérico, formato de arquivo ou comportamento padrão são registradas no [`CHANGELOG.md`](CHANGELOG.md), com o motivo.
- Propostas grandes começam numa issue ou discussão antes do código, para não haver trabalho perdido.

## Como contribuir e como virar colaborador

- Qualquer pessoa pode abrir issue, discussão ou pull request, seguindo o [`CONTRIBUTING.md`](CONTRIBUTING.md) e o [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md).
- Contribuição aceita é creditada no histórico do git e no `CHANGELOG.md`.
- Quem fizer contribuições consistentes ao longo do tempo pode ser convidado pelo mantenedor a revisar pull requests ou a ter permissão de escrita. Se isso acontecer, este arquivo será atualizado com os nomes e o papel de cada pessoa.

## Se o projeto parar

Se o mantenedor deixar de manter o projeto, isso será dito no README. O código continua disponível sob a licença do repositório ([`LICENSE`](LICENSE)), e qualquer pessoa pode continuá-lo num fork.

---

*English:* GUARACI is a single-maintainer project. The maintainer (see [`CITATION.cff`](CITATION.cff)) decides what is merged and released; decisions that change numerical results, file formats or defaults are recorded in [`CHANGELOG.md`](CHANGELOG.md). Anyone may contribute under [`CONTRIBUTING.md`](CONTRIBUTING.md); sustained contributors may be invited as reviewers, and this file will then list them.
